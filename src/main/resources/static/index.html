    Packing instructions

    From bug to clear handoff.

    1. 01

      Record the browser side

      Open Chrome DevTools → Network. Clear the existing requests, reproduce the problem, then export the recording as a HAR file. A short recording keeps the useful bits easy to find.

    2. 02

      Add the server side

      Import NDJSON, a JSON array, or Spring Boot text logs from the same incident. Request IDs and trace IDs connect the evidence. Without shared IDs, logs remain visibly unlinked.

    3. 03

      Review, then share

      Inspect failed requests, review redactions, and add any custom values to hide. Download a standalone HTML report, Markdown, or JSON. The original files are never included in the report.

    Nothing is saved between sessions. Download a report before clearing the workspace or closing the page.
