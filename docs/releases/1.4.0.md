BugParcel 1.4.0 brings more captured evidence into the same local correlation and redaction workflow.

- Import Charles XML, mitmproxy format-21 HTTP flows/HAR, Postman/Newman run results, and Playwright trace ZIPs.
- Combine log folders, quoted globs, gzip and ZIP files, including numbered/date-rotated logs.
- Retrieve logs explicitly through CLI file/HTTP URLs, Loki, or Elasticsearch. Loki probes one extra result to distinguish an exact limit from truncation.
- Inspect completion-time timelines, SVG waterfalls, repeated-error groups, and incident/request comparisons.
- Review redactions and generate standalone HTML/Markdown/JSON or redacted request snippets and replay templates.

**Downloads**

- `BugParcel-1.4.0.zip`: portable application and launchers; requires Java 17+.
- `bugparcel-1.4.0.jar`: runnable application/CLI.
- `sample-report.html`: fictional, redacted standalone report; download and open in a browser **without Java**.
- `demo.gif`: short recording of the synthetic checkout workflow.
- `SHA256SUMS.txt`: SHA-256 checksums for all four assets.

The tagged GitHub Actions workflow builds and tests on Java 17, creates the ZIP/JAR/sample report, verifies checksums, attaches every asset to a draft, and only then publishes the release. The GIF is recorded from the local UI using fictional data.

Automatic redaction is bounded and pattern-based. Review evidence before sharing. Import fidelity and retrieval limits are documented in the [input guide](https://github.com/Nikkilodeonee/BugParcel/blob/v1.4.0/docs/inputs.md).
